# Code Review

Find problems in code and suggest fixes.

## Design principles

- Multiple subtle issues in a single codebase — must find all of them, not just the obvious one.
- Issues range from security vulnerabilities to logic bugs to performance problems to style violations.
- The model must prioritize issues by severity and not miss any critical ones.
- Include code that looks fine on first glance but has subtle correctness issues.
- Verification: output must identify specific issues with file/line references.
