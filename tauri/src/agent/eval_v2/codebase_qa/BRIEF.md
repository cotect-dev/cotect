# Codebase Q&A

Answer questions that require reading multiple files.

## Design principles

- Questions like "What happens when X calls Y?" that require synthesizing information from 3+ files.
- No single file contains the complete answer — the model must read, correlate, and reason across files.
- Include questions about runtime behavior, configuration effects, and data flow.
- Verification: output must contain specific factual answers derived from cross-file analysis.
